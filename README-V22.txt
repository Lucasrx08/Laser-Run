V22 — L7 Jeux Olympiqu’EPS + dossards JO

L7
- L7 est une copie fonctionnelle de la L6.
- 4 boucles / 3 passages au tir.
- Mode 3.
- Les 50 secondes démarrent à la première cible touchée.
- Rechargements illimités.
- Seul le bouton CIBLE TOUCHÉE est utilisé.
- À 50 s, les cibles restantes deviennent rouges.
- Fin immédiate si les 5 cibles sont validées avant 50 s.

CODE JO
- Code à 4 chiffres différent pour chaque classe.
- Code calculé automatiquement à partir de la classe et de l’année scolaire.
- Visible dans l’onglet JO de l’espace professeur.
- L’élève saisit le code une seule fois pour ouvrir la L7.
- Une tentative L7 commencée est verrouillée.
- Une nouvelle tentative nécessite le code professeur sur la tablette concernée.

CRISTAUX
- L1 à L6 : 4 / 3 / 2 cristaux selon le classement.
- L7 : 12 / 9 / 6 cristaux.
- Attribution à la nation, une seule fois.

DOSSARDS
- Générés automatiquement depuis le classement individuel de la L6.
- Numéro = place obtenue en L6.
- A4 portrait avec 2 dossards A5 paysage par page.
- Une seule ligne pointillée horizontale entre les deux dossards.
- Design jeune dans la charte Laser Run : #c7dbdf, #323c3a, #ebe5df, #f7b738.
- Nom/prénom, classe, nation, numéro, Laser Run, Jeux Olympiqu’EPS et année scolaire.
- Le bouton ouvre directement l’impression : choisir « Enregistrer au format PDF » / « Save as PDF ».

ANNÉE SCOLAIRE
- Automatique.
- Bascule au 1er août.
- Exemples : septembre 2026 → 2026-2027 ; janvier 2027 → 2026-2027 ; septembre 2027 → 2027-2028.
