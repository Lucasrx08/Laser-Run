V35 — Restauration complète

MASS-START
- Les Athlètes 1 ET Athlètes 2 sont visibles simultanément en mode course.
- Organisation plein écran : deux colonnes de groupes, chacune en 3 x 5 athlètes.
- Les 30 athlètes peuvent arrêter leur chrono sans faire défiler la page.
- Saisie tir visible directement sous chaque athlète.
- Une saisie terminée change visuellement l'état du bouton.
- Les touches L4 alimentent immédiatement le profil de l'athlète.

RELAIS
- 15 nations visibles en 5 x 3 en mode course, sans scroll.
- Le bouton tir affiche maintenant l'état réel : à compléter / partiel / saisi.
- Après saisie des deux athlètes, la tuile indique « Saisi » avec le total.
- Les touches L5 alimentent immédiatement les profils.

POURSUITE
- La voix n'est plus utilisée pour donner le top exact.
- Voix = préparation seulement.
- Départ = 3 bips courts (3,2,1) + bip long exact au départ.
- Le premier départ bénéficie d'un vrai pré-départ 3-2-1 avant le lancement du chrono.
- Reprise après pause sans nouveau pré-départ.
- Mise en page plein écran compacte et lisible.

DRAPEAUX
- Les 15 nations utilisent maintenant la même table de drapeaux partout.
- Correction Pologne, Slovénie, Autriche, Estonie, Lettonie, Lituanie, Ukraine, etc.

Base : V34. Aucune règle pédagogique modifiée.
