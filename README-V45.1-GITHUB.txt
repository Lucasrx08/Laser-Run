LASER RUN 6e — V45.1

Base : V45 validée.

MODIFICATIONS
- Export iDoceo d'évaluation à 8 colonnes :
  Nom Prénom | Précision /4 | Rapidité /4 | Respiration /4 |
  Réussite tir % | Niveau tir /4 | Cristaux | Niveau cristaux /4
- Précision = moyenne L1 + L4
- Rapidité = moyenne L2 + L5
- Respiration = moyenne L3 + L6
- Niveau tir : <40%=1 ; 40-59%=2 ; 60-79%=3 ; >=80%=4
- Cristaux = total actuel de la nation
- Niveau cristaux = position de la nation répartie en quatre quarts
  (meilleur quart=4, dernier quart=1)
- Profils athlètes harmonisés avec L1+L4 / L2+L5 / L3+L6
- Dossards JO : numérotation unique et continue entre vague 1 et vague 2
- L'ancien export détaillé L1-L7 est remplacé, supprimant aussi l'anomalie
  de colonne Relais liée à l'ancien champ l5.time / relayTime.
- Cache PWA renouvelé en V45.1.
- Design V45 des dossards conservé.
