LASER RUN 6e — V38.1 ÉQUITÉ DES BINÔMES

RÈGLE GLOBE DE CRISTAL
Pour toutes les leçons, une nation doit être comparée comme un binôme.

L1 / L2 / L3 / L4 / L6 / L7
- 2 athlètes avec un temps : temps Athlète 1 + temps Athlète 2.
- 1 seul temps disponible : temps de l'athlète × 2.

L5 — RELAIS
- 2 athlètes : le chrono du relais est déjà le temps total de la nation, il n'est donc pas additionné deux fois.
- 1 seul athlète dans la nation : temps du relais × 2.

CONTRÔLE VISUEL
- Le Globe affiche toujours le temps réellement utilisé pour classer la nation.
- Quand un temps a été doublé, « ×2 » apparaît à côté du temps.

PROFILS / TIRS
- Corrections V38 conservées :
  * Mass-start L4 x/15 visible dans le profil ;
  * Relais L5 x/15 visible dans le profil ;
  * taux de réussite calculé à partir des tirs L4 et L5 ;
  * chrono et tirs peuvent être enregistrés séparément sans perdre une donnée.

BARÈMES
- L1 à L6 : places 1 à 4 = 4 cristaux ; 5 à 8 = 3 ; 9 et + = 2.
- L7 : valeurs validées conservées dans l'application : 12 / 9 / 6.
